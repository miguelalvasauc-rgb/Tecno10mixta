## 🧠 BLOQUE 1 — Tecnologías del Mañana

### Secuencia 1 — Inteligencia Artificial
| Término | Definición simple |
|---|---|
| IA (Inteligencia Artificial) | Máquinas que imitan capacidades humanas como aprender y decidir |
| Machine Learning | Máquinas que aprenden patrones de datos sin programación explícita |
| NLP (Procesamiento de Lenguaje Natural) | Capacidad de computadoras para entender y generar lenguaje humano |
| Red Neuronal | Sistema de computación inspirado en el cerebro humano |
| Algoritmo | Conjunto de instrucciones paso a paso para resolver un problema |
| Chatbot | Programa que simula conversación humana |
| Asistente Virtual | Software con IA que responde comandos de voz o texto |
| Big Data | Conjuntos de datos masivos que requieren herramientas especiales |
| Sesgo Algorítmico | Cuando un algoritmo produce resultados injustos por datos de entrenamiento limitados |
| IA Generativa | IA que crea contenido nuevo: texto, imágenes, música, video |

### Secuencia 2 — Realidad Virtual
| Término | Definición simple |
|---|---|
| Realidad Virtual (VR) | Mundo digital completamente inmersivo que reemplaza al real |
| Realidad Aumentada (AR) | Capa de información digital sobre el mundo real |
| Realidad Mixta (MR) | Objetos digitales que interactúan con el mundo real |
| Inmersión | Sensación de "estar realmente dentro" de un entorno digital |
| Interacción | Capacidad de manipular objetos y moverse dentro del mundo virtual |
| Avatar | Representación digital del usuario dentro del mundo virtual |
| Metaverso | Espacio virtual persistente, compartido y económico |
| Háptico | Tecnología que simula el tacto (vibraciones, resistencia) |
| Renderizado | Proceso de generar imágenes 3D a partir de modelos |
| Tracking | Seguimiento de movimientos del usuario para reflejarlos en VR |

### Secuencia 3 — Robótica
| Término | Definición simple |
|---|---|
| Robot | Máquina programable que realiza tareas automáticamente |
| Sensor | Dispositivo que detecta información del entorno |
| Actuador | Dispositivo que ejecuta acciones físicas |
| Procesador | "Cerebro" del robot que toma decisiones |
| Algoritmo | Conjunto de instrucciones paso a paso |
| Autonomía | Capacidad de actuar sin intervención humana |
| Teleoperación | Controlar un robot a distancia |
| Retroalimentación | El robot ajusta su comportamiento según resultados |
| Cinemática | Estudio del movimiento de las partes del robot |
| Brazo robótico | Estructura con articulaciones que imita un brazo humano |
| Enjambre robótico | Grupo de robots que colaboran como abejas o hormigas |

## 🔐 BLOQUE 2 — Datos, Diseño y Ciberseguridad

### Secuencia 4 — Ciencia de Datos
| Término | Definición simple |
|---|---|
| Dato | Unidad básica de información (número, texto, imagen) |
| Base de datos | Conjunto organizado de datos |
| Big Data | Datos masivos que requieren herramientas especiales |
| Algoritmo | Conjunto de instrucciones paso a paso para resolver un problema |
| Ciencia de Datos | Disciplina que extrae conocimiento de datos |
| Visualización | Representar datos de forma gráfica para entenderlos mejor |
| Patrón | Tendencia o regularidad que se repite en los datos |
| Predicción | Estimar lo que ocurrirá en el futuro basado en datos del pasado |
| Sesgo algorítmico | Cuando un algoritmo produce resultados injustos |
| Filtro burbuja | Algoritmo que solo muestra lo que ya te gusta |
| Datos abiertos | Información pública que cualquiera puede usar y analizar |

### Secuencia 5 — Hojas de Cálculo
| Término | Definición simple |
|---|---|
| Hoja de cálculo | Software de cuadrícula para organizar y analizar datos |
| Celda | Cuadrito individual donde se introduce un dato |
| Fila | Conjunto horizontal de celdas (numeradas) |
| Columna | Conjunto vertical de celdas (con letras) |
| Rango | Grupo de celdas seleccionadas (ej: A1:C5) |
| Fórmula | Operación que empieza con = y calcula automáticamente |
| Función | Comando predefinido (SUMA, PROMEDIO, SI) |
| Promedio | Suma de valores dividida entre cantidad de valores |
| Porcentaje | Parte de un total expresada en base 100 |
| Gráfica | Representación visual de datos |
| Infografía | Combinación de datos, gráficas y diseño para comunicar un mensaje |

### Secuencia 6 — Seguridad Digital
| Término | Definición simple |
|---|---|
| Ciberseguridad | Protección de sistemas y datos en el entorno digital |
| Hacker | Persona que explora sistemas informáticos (puede ser legal o ilegal) |
| Phishing | Engaño por correo o mensaje para robar datos personales |
| Ransomware | Virus que secuestra tus archivos y exige rescate |
| Malware | Software malicioso: virus, troyanos, spyware |
| Spyware | Software que espía tu actividad sin permiso |
| Cifrado | Convertir información en código ilegible para protegerla |
| Contraseña | Clave secreta para acceder a una cuenta |
| Verificación en dos pasos (2FA) | Segunda capa de seguridad además de la contraseña |
| Huella digital | Rastro de datos que dejas al usar internet |
| Backup / Copia de seguridad | Reserva de archivos importantes en caso de pérdida |
| Firewall | Barrera que bloquea accesos no autorizados a tu red |
| VPN | Red privada virtual que oculta tu ubicación real |

### Secuencia 7 — Soluciones Digitales
| Término | Definición simple |
|---|---|
